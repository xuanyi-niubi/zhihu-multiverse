## 修复「首页随便点击就闪现蓝色 / 跟卡了一样」

### 现象
首页（`/`）在 Chrome 里随便点击 —— 点输入框、点标题、点空白皆可 —— 画面会闪一下蓝，
观感像掉帧卡住。

### 诊断方法（可复用，脚本留档在 `work/`，已被 .gitignore 的 `/work/` 覆盖）
用 CDP 连本地 dev server（调试端口 9224）做四件事：
1. `Input.dispatchMouseEvent` 发**真实**鼠标事件 —— 不能用 `element.dispatchEvent`，
   否则 `:focus-visible`、选区、`:active` 的行为全部不真实。
2. `MutationObserver` 开 `attributeOldValue: true`，抓「谁在变、旧值 → 新值」。
   这是定位本次根因的决定性手段。
3. `Emulation.setDeviceMetricsOverride` 固定到用户实际窄屏宽度（500px）。
   桌面视口下输入框/CTA 落在视口外，`dispatchMouseEvent` 点不到，等于白测。
4. `Page.captureScreenshot` 点击前后连拍 + 肉眼比对。
脚本：`work/diagnose-click-blue3.mjs`（定位）、`work/verify-fix.mjs`（复验）、
`work/measure-tilt-perf.mjs`（帧率/长任务指标）。

### 根因（均有实测证据）
1. **`.obs-signal` 尺寸硬跳变** —— `FateProjectionConsole.tsx` 写死
   `size={focused || collapsing ? 24 : 16}`，而 CSS 里 `.obs-signal` 没有尺寸过渡。
   点击那一瞬间，这颗带 14px 外发光的青蓝脉冲点面积直接弹大 125%。
   实测：`width:16px;height:16px` → `width:24px;height:24px`，中间零过渡值。
2. **AstralDial 视差走 React state** —— `pointermove` 挂在 window 上，每个 rAF 都
   `setTilt()`，触发重渲染 27 个 SVG 元素（4 环 + 12 刻度 + 7 节点 + 2 准线 + 焦点），
   且每个元素都新造一个内联 style 对象。实测 120 次指针移动 → 237 次 style 写入。
3. `.obs-dial__svg` 是 660~1120px 的巨型 SVG，没有合成层提示，
   transform 每帧变化都要重新光栅化整台仪器。

关键：**帧率实测是满的（16.7ms / 0 掉帧）**，所以这是「视觉突变」而非「性能卡顿」——
用户口中的"卡"指的是节奏错乱的瞬变，不是丢帧。定位时不要被性能指标带偏。

### 修复
- `src/components/visual/AstralDial.tsx`：视差改为 `svgRef.current.style.setProperty()`
  直接写 `--obs-tilt-y` / `--obs-tilt-x`，**完全绕开 React render**；移除受控 style。
  SSR 与水合首帧输出因此逐字节一致。
- `src/app/globals.css` `.obs-signal`：补 `transition: width/height 320ms var(--obs-ease)`
- `src/app/globals.css` `.obs-dial__svg`：补 `will-change: transform`

### 验证
- 蓝点尺寸轨迹：改前 `[16, 24]` → 改后 `[16,18,19,21,22,23,24]`；缩回同样平滑。
- 指针移动期间 `dialClass: 0 / nodes: 0` —— React 零重渲染。
- `npm test` 98 文件 / 1538 用例全绿；`npm run build` exit 0。
- 未触碰 §33（`<Kanshan` 恰好 4 处）与 §34（10 个 keyframes，游戏层零新增）。

### 踩坑（重要）
- **同一文件的两个 Edit 并行发出会互相覆盖**：先发的被后发的写回整体覆盖，
  但工具两次都报 success。本次 `.obs-signal` 那条就是这样被静默吞掉的
  （`.obs-dial__svg` 那条赢了）。**同一文件的多次编辑必须串行。**
- **`npm run build` 与正在跑的 `npm run dev` 抢 `.next` 目录**，
  会把 dev server 直接挤崩（端口 3000 变 False）。改完要重新 `npm run dev`。
- dev server 重启后**首次访问要现编译**，CDP 脚本固定等 7s 不够，
  应轮询等目标元素（如 `textarea`）出现再继续。
